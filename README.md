# Terminal-Based CLI

A simple command-line Personal Diary and Expense Tracker built with Python.

This project helps users write diary entries, manage daily expenses, and view monthly spending summaries. All data is stored locally using JSON files.

## Features

### Diary

* Write a new diary entry
* Read saved diary entries
* List all diaries
* Delete a diary entry

### Expenses

* Add daily expenses
* View saved expenses
* View expense details
* Delete expense records
* Check monthly expense summary

## Technologies Used

* Python
* JSON
* Pathlib
* Datetime

## Project Structure

Terminal-Based-CLI

* Diary/
* Expenses/
* Data/

## How to Run

1. Clone the repository
2. Open the project folder
3. Run:

```bash
python main.py
```
